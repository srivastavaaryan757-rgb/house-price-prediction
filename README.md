🏠 House Price Prediction using Machine Learning
📌 Project Description

This project uses Machine Learning to predict house prices based on different features such as area, number of rooms, location, and other property details. The model helps estimate the price of a house using regression algorithms.

📊 Dataset Information
Dataset Source: Kaggle
Kaggle House Prices Dataset
Type: Regression Dataset
Target Variable: House Price
